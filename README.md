# pw2-app-web

---=== Descrição do projeto ===---
Este projeto tem como objetivo a realização do controle da bovinocultura de leite, sendo eles o controle de
animais e suas categorias, propriedades, piquetes, insumos, estoque, produção mensal e diária.

---=== Objetivo da aplicação ===---
Estar realizando a criação, busca, exclusão e atualização dos dados.
